📥 นำเข้าโครงการจาก KML/KMZ (ทั้งปีในคลิกเดียว)
1️⃣ไปที่หน้า บันทึก GPS / โครงการ → แท็บ นำเข้า KML/KMZ
2️⃣อัปโหลดไฟล์ .kml / .kmz (Export จาก Civil 3D / Google Earth) → เลือกปีงบประมาณ ให้ถูก (กันชื่อซ้ำข้ามปี)
3️⃣ระบบดึงให้อัตโนมัติ: ชื่อสายทาง · เลขทางหลวง · ค่าก่อสร้าง (×1,000,000) · จังหวัด · กิจกรรม · แนวเส้นทางจริง — 1 เส้น = 1 ช่วง (โครงการหลายช่วงจะมีป้าย · N ช่วง)
4️⃣ตรวจ Preview บนแผนที่ + ตาราง → ใช้ปุ่ม เลือกทั้งหมด / ยกเลิกทั้งหมด หรือติ๊กรายตัว → กด ยืนยันนำเข้า
🔢รหัสโครงการรันต่ออัตโนมัติ (P122, P123…) · รหัสสัญญา ทล.{เลขทางหลวง}-{ปี}-Pxxx
🛡️กันลงซ้ำ: ชื่อโครงการ + ปีเดียวกันที่มีอยู่แล้วจะถูกข้าม (ไม่ทับ ไม่เพิ่ม) · ชื่อเดิมคนละปีถือเป็นคนละโครงการ
🗑ลงผิด/อยากเริ่มใหม่: เมนูชีท 🛠 ระบบ สท.2 → ลบโครงการตามปีงบ แล้วนำเข้าใหม่ (ช่อง กม. เว้นว่างให้กรอกเอง)
🧹ผู้ดูแล: เมนูชีท 🛠 ระบบ สท.2 → ตรวจแถวซ้ำ (ดูอย่างเดียว) / รวมแถวซ้ำ + แปลงเดือนเป็น พ.ศ. (สำรองชีตให้ก่อนทุกครั้ง) · เดือนในชีตความก้าวหน้าเก็บเป็นข้อความ พ.ศ. เช่น 2569-11
👥ล็อกอินด้วย PIN กลางของสำนัก (ชุดเดียวกับทุกแอป) — สิทธิ์ในแอปนี้ได้อัตโนมัติตามระดับในฐานกลาง (ผู้ดูแลกลาง→Admin · ผู้บริหาร→Executive · ระดับกลาง→IT · เจ้าหน้าที่→ตามที่ผู้ดูแลตั้ง) · ผู้ดูแลกำหนดข้อยกเว้นรายคน (ยกระดับ/ปิดกั้น) ได้ที่หน้า สิทธิ์ผู้ใช้งาน ไม่ต้องเพิ่มรายชื่อทีละคน · ล็อกอินผิดเกิน 10 ครั้งใน 10 นาที ระบบปิดรับ 5 นาที
📜ทุกการแก้ไขความก้าวหน้า/ข้อมูลโครงการเก็บค่าเดิมไว้ — ดูได้จากปุ่ม 📜 ประวัติการแก้ไข ท้ายหน้ารายละเอียดโครงการ (ชีต "ประวัติแก้ไข")
🧭เมนู วางแผนเดินทาง: ติ๊กเลือกโครงการ เลือกจุดเริ่ม ระบบจัดลำดับเส้นทางสั้นสุด แบ่งวันตามจำนวน/กม./ชั่วโมง ใช้ ระยะทางและเวลาขับจริงจาก Google Maps รวมขากลับจุดเริ่มต้น พร้อมลิงก์นำทางรายวัน · บันทึกแผนลงชีตให้ทีมเห็น หรือส่งเข้ากลุ่ม LINE ได้

👥 สิทธิ์ผู้ใช้งาน
🏛️ สิทธิ์อัตโนมัติจากฐานข้อมูลกลาง
ทุกคนที่มี PIN ในฐานกลาง (ชีต AUTH_PIN ใน Master DB) เข้าแอปนี้ได้ทันทีตามระดับของตน ไม่ต้องเพิ่มรายชื่อที่นี่ — ตั้งค่าว่าแต่ละระดับในฐานกลางได้สิทธิ์อะไรในแอปนี้:
Admin = จัดการทุกอย่าง · IT = บันทึก/แก้ไขข้อมูล · Executive = ดู+ส่งออกรายงาน · เข้าไม่ได้ = ล็อกอินไม่ผ่าน
🎯 กำหนดสิทธิ์เฉพาะราย (ข้อยกเว้น)
ใช้เมื่อบางคนต้องได้สิทธิ์ต่างจากค่าเริ่มต้น เช่น ให้นายช่างบางคนบันทึกความก้าวหน้าได้ (IT) หรือปิดกั้นบางคนไม่ให้เข้าแอปนี้ · คนที่ไม่อยู่ในรายการนี้ใช้สิทธิ์ตามฐานกลางโดยอัตโนมัติ
ชื่อรหัสบุคคลระดับกลางสิทธิ์ในแอปนี้สถานะแก้ไขล่าสุดจัดการ
กำลังโหลด...
"ปิดกั้น" = เข้าแอปนี้ไม่ได้แม้ฐานกลางจะให้สิทธิ์ (ยังใช้ระบบอื่นของสำนักได้ตามปกติ) · "ใช้ค่าเริ่มต้น" = ลบข้อยกเว้น กลับไปตามฐานกลาง · การเปลี่ยนแปลงมีผลเมื่อผู้ใช้เข้าระบบครั้งถัดไป · บันทึกทุกรายการลงชีต Log
🗂️ บัญชีรหัสแอปแบบเดิม (ชีต Users)
สำหรับคนที่ยังไม่มี PIN กลาง (ล็อกอินด้วยรหัสของแอปนี้) · แถวที่ผูก Central_name ไว้ยังใช้ได้ แต่แนะนำกด "ย้ายไปข้อยกเว้น" แล้วลบแถวทิ้ง — ชีตนี้ว่างได้ทั้งแท็บ
ชื่อRoleหน่วยงานเข้าระบบด้วยเข้าใช้ล่าสุดจัดการ
🔔 ตั้งค่า LINE Messaging API
⚠️
LINE Notify ปิดบริการถาวรแล้ว (31 มีนาคม 2568)
ระบบนี้ใช้ LINE Messaging API แทน ซึ่งต้องสร้าง Messaging API Channel ใน LINE Developers Console (developers.line.biz) และ Bot ต้องถูกเพิ่มเข้ากลุ่มก่อนจึงจะส่งข้อความได้
🔑 Channel Access Token
📋 วิธีขอ Channel Access Token:
1. ไปที่ developers.line.biz/console → Login
2. เลือก Provider → สร้าง Channel ประเภท Messaging API
3. ไปที่ Tab Messaging API → กด Issue ที่ Channel access token
4. Copy token แล้ววางในช่องด้านบน
🎯 Target ID (ปลายทางรับข้อความ)
📋 วิธีหา Target ID:
ส่งหา User: เพิ่ม Bot เป็นเพื่อน → ส่งข้อความหา Bot → ดู userId จาก Webhook event
